# \# VoiceStock

# 

# Voice-first inventory manager for small shops, built for the Amazon Developer Hackathon (Alexa+ track).

# 

# \## What it does

# Ask Alexa+ what's expiring, low, or sold out. Sales update stock automatically, 

# and the system finds the best wholesaler and places orders when stock runs low, 

# with live delivery tracking.

# 

# \## Track

# Alexa+ (simulated Alexa+ experience)

# 

# \## Tech stack

# \- Backend: Python, FastAPI, MCP

# \- Database: PostgreSQL (AWS RDS)

# \- AI: Amazon Bedrock, Amazon Polly, Amazon Transcribe

# \- Frontend: Next.js
